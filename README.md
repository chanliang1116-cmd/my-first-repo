# 我的第一个仓库

这是 chanliang1116-cmd 的第一个 Git 仓库，用于验证本机 Git 配置和 GitHub 连接。

- 作者：chanliang1116-cmd
- 环境：macOS 27.2.1 (arm64)
- 认证方式：SSH (ed25519)

## 目录结构

```
my-first-repo/
├── .gitignore   # 告诉 Git 哪些文件不用上传（系统缓存、日志等）
├── README.md    # 项目说明文档，也就是你正在读的这个文件
└── .git/        # Git 的内部记录，不要手动改动
```

## 如何使用

1. 克隆到本地：`git clone git@github.com:chanliang1116-cmd/my-first-repo.git`
2. 进入目录：`cd my-first-repo`
3. 修改文件后依次执行：`git add -A`、`git commit -m "说明"`、`git push`

目前它是一个练习用的空壳仓库，没有代码。适合用来熟悉提交、推送、分支这些基本操作，
